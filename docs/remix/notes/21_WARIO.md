# 0x21 WARIO port notes

Source: `.toolchain/pkgs/smashremix-src/src/Wario/WarioSpecial.asm` (scope WarioNSP, WarioUSP, WarioDSP).
Port: `decomp/src/ft/ftremix/wario/ftremixwario.c`, table `dFTRemixWarioProcs` (23 entries, the whole worklist).

## 1. Vanilla patches

None. WarioSpecial.asm has no `OS.patch_start` blocks and no `j`/`jal` hooks into vanilla code. Its
only vanilla interaction is the Remix action tables (generated by `tools/gen_remix_actions.py`).

Vanilla bytes the asm inlines with `OS.copy_segment` (from `baserom.us.z64`) were reproduced in C, not patched:

| Remix routine | Copied vanilla source (US ROM offset) | Port |
|---|---|---|
| ground/air/recoil statuses | Mario NSP `0xD0A54`, `0xD0A64`, `0xD0A94`, `0xD0AA8`, `0xD098C`, `0xDE2EC`, `0xDE30C` | `ftRemixWarioSpecialN*SetStatus`, `*ToAir`, `*ToGround` |
| WarioNSP.ground_physics_ | Mario ground friction `0x543B4`, `0x543EC` (`0x800D8BB4`) | `ftRemixWarioSpecialNGroundProcPhysics` (traction 0.5) |
| WarioUSP.physics_ | air physics `0x548F0` (`0x800D91EC` head) | `ftRemixWarioSpecialHiApplyAirVel` |
| WarioUSP.main_ | Fox up special end `0xD7190` (`0x8015C750`) | `ftRemixWarioSpecialHiProcUpdate` |
| WarioUSP.collision_ | Mario up special collision `0xD0D98`, `0xD0E14` (`0x80156358`) | `ftRemixWarioSpecialHiProcMap` (lag `0x3E805C29`) |
| WarioDSP.begin_landing_ | Captain Falcon landing `0xDAB2C`, `0xDAB48` (`0x801600EC`) | `ftRemixWarioSpecialLwBeginLanding` |

## 2. Shared subsystems

None. Every helper called (FGM, efManager, ft/mp physics, collision) is a vanilla decomp function.
No `REMIX-TODO` markers.

## 3. Vanilla calls used (for reviewers)

- `FGM.play_` -> `func_800269C0_275C0` (as in `ftremixcommand.c`); ids `0x117` (recoil), `0x5E` (jump).
- `0x8013F474` -> `ftCommonKneeBendGetInputTypeCommon` (jump check, see uncertainty A).
- `0x800FF3F4` -> `efManagerDustHeavyDoubleMakeEffect(p_translate, 1, 1.0F)` (jump smoke).
- `0x8015F874` -> `ftCaptainSpecialNGetAngle`, `0x800303F0` -> `__sinf` (NSP air move rise).
- `0x80160370` -> `ftCaptainSpecialHiProcInterrupt` (USP turn; declared extern in the port).
- `0x801438F0` -> `ftCommonFallSpecialSetStatus` (USP main_).

## 4. Constants derived from the Remix ROM (not named in source)

The asm refers to these by name only through the generated action tables. Values were read from the
Remix action arrays in `baserom.remix.z64` (array of Wario id `0x21` at RAM `0x804A9850`, Kirby id `0x08`
at `0x804A1BA0`):

- Wario: `NSP_Recoil_Ground` = `0xE5`, `NSP_Recoil_Air` = `0xE6` (array indices 9 and 10, i.e. status 0xDC + i). The
  `scope Action` names `BodySlam`..`GroundPoundAir` = `0xDF`..`0xE4` come from Wario.asm.
- Kirby (`Kirby.Action.WARIO_NSP_*`): `Ground` = `0x138`, `Air` = `0x139`, `Recoil_Ground` = `0x13A`,
  `Recoil_Air` = `0x13B` (Kirby array entries 0x138..0x13B point at the WarioNSP routines).

## 5. Uncertainties

A. **Jump check (WarioSpecial.asm:225-228).** The asm calls `0x8013F474` and jumps when v0 != 0. The port
   maps this to `ftCommonKneeBendGetInputTypeCommon(fp) != FTCOMMON_KNEEBEND_INPUT_TYPE_NONE`. Confirmed
   that the decomp function returns 0 for no input, but its name is kneebend, so the mapping relies on the
   asm's "check jump" comment.

B. **check_recoil_ does not clear temp 1 (asm 546-590).** The port follows the asm: `flag0` (temp 1) stays set
   after the recoil starts. The next grounded collision re-checks it. Only `ground_initial_`/`air_initial_`
   reset it.

C. **Up special BEGIN air-drift (asm 855-866).** For temp 3 == BEGIN the asm calls
   `0x800D8FA8` (`ftPhysicsCheckClampAirVelXDecMax`) a second time. It returns FALSE on that path, so the call
   changes nothing and the port omits it.

D. **Down special BEGIN y clamp (asm 1240-1246).** Vanilla tests the sign bit of y; the port uses `y < 0.0F`.
   The only difference is that -0.0 becomes +0.0.

E. **Up special collision landing lag (asm 1020 + copied `ori` at 0xD0E34).** The value is the upper
   half `0x3E80` from Remix and the lower `0x5C29` from Mario's copied `ori`, giving `0x3E805C29` (about
   0.2507). The main_ landing lag is plain `0x3E80` (0.25). Both are kept as separate macros.

F. **Up special main_ (asm 784-800).** The Remix copy reads `anim_frame` at GObj `0x78` as the Fox routine
   does. The landing-lag stack slots map to `is_goto_landing = FALSE`, `landing_lag = 0.25`,
   `is_allow_interrupt = FALSE`. Confirmed from the stores at asm lines 789-793.

G. **Ground jump after the wall check (asm 220-243).** `ground_to_air_` runs before the jump velocity and
   effects. The port follows the same order.
