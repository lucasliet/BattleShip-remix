# F10 menu feature: Music Title at Match Start

Toggle: `Toggles.entry_show_music_title` ("Music Title at Match Start", Toggles.asm, defaults 1/0/1/1). Read with
`gmRemixToggle(show_music_title)`; the asm also requires `Toggles.entry_play_music`, which the port checks too.

## Route taken: port overlay (not the vanilla sprite path)

The asm draws the banner with `Render.load_font` and `Render.draw_string_` (font from the Remix file, text drawn as
glyph objects). The port does not draw that font, so the banner is a port overlay:

- `port/remix/remix_overlay.h/.cpp`: `remix_overlay_show_text(text, seconds)` forwards to libultraship's
  `GameOverlay::TextDrawNotification` (the engine toast). The GameOverlay draws its notifications every frame inside the
  ImGui pass of the window, so no own ImGui window was added.
- `port/remix/remix_music_title.h/.cpp`: `remix_music_title_show(bgm_id, seconds)` looks up the title row and shows
  `"<track> - <game>"` on one line (the GameOverlay has no second line; the asm shows two lines and a note glyph).
- `port/remix/remix_music_titles_data.inc`: rows `{ bgm_id, track, game }` generated by
  `tools/gen_remix_music_titles.py` from the Smash Remix source (`BGM.asm` string_table, `Toggles.asm` entry titles,
  `midi.asm` insert calls and add_game names). 308 rows of 375 BGM ids. Menu tracks and extra MIDIs have no title row,
  which matches the asm (their string_table entry is 0, so the asm shows nothing for them).
- `decomp/src/gm/gmremixmusictitle.h/.c`: `gmRemixMusicTitleShowAtCountdown()` checks the two toggles, reads
  `syAudioGetBGMPlaying(0)` and calls `remix_music_title_show(id, 4.0f)`.

## Hook

- `decomp/src/if/ifcommon.c`, `ifCommonCountdownMakeInterface` (0x80112668, the GO lights creation that the asm hooks
  at 0x8011268C): a `#ifdef REGION_REMIX` call before `return sobj;`. Same place as the asm, so it runs for every
  countdown (VS, 1P, bonus), like the asm does.
- Not hooked: the asm's `_destroy` at the GO! text (0x801120D4). The overlay fades on its own after 4 seconds, so the
  banner can outlive the GO! moment by a little.

## Not ported / differences

- Note glyph (0x80 in the asm string) is dropped: the ImGui font has no such glyph.
- Single line instead of track on top and game below.
- Fade and placement are the GameOverlay's, not the asm's rectangle.

## What the lead should check on screen

- Start with `SSB64_START_SCENE` on a VS match with a stage song (e.g. Dream Land, Peach's Castle).
- With `SSB64_REMIX_TOGGLES='Music Title at Match Start=1'` (and Play Music on) a message appears during the lights and
  fades within about 4 seconds. Expected text for Dream Land: `Dream Land - Kirby Super Star`.
- With `Music Title at Match Start=0` nothing appears.
- With the BGM on a menu or extra track (no title row) nothing appears.

## Build

- New files: `port/remix/*.cpp` is globbed with CONFIGURE_DEPENDS, the decomp `gm` glob is not. Re-run the cmake
  configure before building so `gmremixmusictitle.c` is picked up.
- Syntax checks: `scripts/remix/syntax-check.sh` gives `syntax-check OK` for `gmremixmusictitle.c` and `ifcommon.c`
  (one pre-existing warning at ifcommon.c:2418, not from this change). The two port `.cpp` files compile with
  `-fsyntax-only` using the game's flags from `build/compile_commands.json`.
- Not built, not run (lead's job).
