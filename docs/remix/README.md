# Smash Remix in the port: documentation index

**Plan and progress live only in [`ROADMAP.md`](ROADMAP.md)** (phases, current position, estimate). Every other file here is a
final-state reference: how Smash Remix 2.0.1 works (read from its source, `.toolchain/pkgs/smashremix-src/src`), how the port
implements it, the deviations and how to test. The open items are in [`patch_audit.md`](patch_audit.md).

ROMs (with SHA), Remix version and the desktop and Switch build steps: [`build_and_roms.md`](build_and_roms.md). Bug write-ups:
[`../bugs/README.md`](../bugs/README.md) (`remix_*` files). In-game tests: skill `remix-smoke-tests`
(`.claude/skills/remix-smoke-tests/`); unit tests: `tests/remix/` (`cmake --build build --target run_remix_mode_tests`).

## Rules for this folder

- English only. A reference describes how things are; state and plans go to `ROADMAP.md`, open items to `patch_audit.md`. A new doc
  gets a row in this index.
- No ROM-derived bytes here (values come from the Remix source).
- `torch/` and `libultraship/` do not cite these docs (independent repositories); `decomp/` may cite `docs/remix/*.md` and `../bugs/`.
