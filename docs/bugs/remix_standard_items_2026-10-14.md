# Remix standard items: ports, spawn extension and generator fix

How the Remix standard items are ported and spawned, the per-item facts found while verifying them, and a generator bug.
Code: `decomp/src/it/itremix/itremix<name>.c/.h`, `itremixspawn.c`, `itremixitems.c` (generated by `tools/gen_remix_items.py`),
`decomp/src/mn/mnvsmode/mnvsitemswitch.c` (VS item switch menu), `tools/gen_remix_actions.py`. Test: `item_cpu_sweep.sh
[kind]...` (Mario idle + Kirby + Yoshi CPUs, every spawned item forced to the kind, 3000 frames, item event counts), with
`SSB64_VS_ITEMS=<1..5>`, `SSB64_REMIX_FORCE_ITEM=<kind>`, `SSB64_REMIX_FORCE_ITEM_AT_P1=1` and `SSB64_REMIX_ITEM_LOG=1` (logs
`[remix-item] spawn|hold|consume|touch|drop|throw|bullet kind=0x..`) (`.claude/skills/remix-smoke-tests/SKILL.md`).

## What exists

- Ports for Cloaking Device, Super Mushroom, Poison Mushroom, Blue Shell, Lightning, Deku Nut, Franklin Badge, Pitfall, Golden
  Gun, Dango, P-Wing, Stopwatch, Basketball and Psyduck. Each exports `dITRemix<Name>ItemDesc`; `tools/gen_remix_items.py` lists
  them in `itremixitems.c` together with the fighter items. Standard items use `ITDesc.p_file = &gITManagerCommonData` (file
  0xFB, patched in place by Remix).
- Spawn extension (`itremixspawn.c`): Remix item n (kind 0x2D+n) is on when bit `nITKindCommonEnd + 1 + n` of `item_toggles` is
  set (n < 12); the 13th (Stopwatch) uses `gITRemixExtendedToggles` bit 0. Weights are the per-stage bytes of
  `Stages.custom_item_spawn_rate_table` in the Remix RAM image. `itManagerMakeAppearActor` and `itManagerSetupContainerDrops`
  add the enabled, ported items after the vanilla entries.
- Vanilla hooks, all under `REGION_REMIX` with the vanilla code intact in `#else`: Cloaking immunity and scene-boundary clear
  (`itRemixClearActiveItems` in `scManagerRunLoop`), Stopwatch hitlag and Speed process hook, Golden Gun shoot path, shared
  Super/Poison Mushroom state, Basketball bounce/FGM/hitlag, Franklin Badge keep-reflect and immunities.
- VS item switch menu: R pages, L toggle-all, icon strip as a Sprite, save/restore of `gITRemixExtendedToggles`, zeroing in the
  comp ruleset and Training, netplay (peer exchange, replay metadata, settings hash; old replays are rejected).
- Rate 5 spawns the first item after about 10 s (~600 frames). A human pickup by input script does not work (the item is still
  in its appear state when A is pressed); use `item_cpu_sweep.sh` or `SSB64_REMIX_FORCE_ITEM_AT_P1=1`.

## Per-item facts

| Kind | Item | Fact |
|---|---|---|
| 0x2D | Cloaking Device | translucency and damage immunity; its routine GObj lives on the interface link (`remix_routine_gobjs_on_effect_link_2026-10-29.md`) |
| 0x2E | Super Mushroom | fighters grow: the routine writes `Size.multiplier_table` (`ftRemixSizeSetMultiplier`) |
| 0x2F | Poison Mushroom | fighters shrink (same path) |
| 0x30 | Blue Shell | the `ITDesc` had `TraRotRpyR` while the asm word 0x0C is 0 (the spawn adds the red shell XObjs itself), so the transform was doubled and the shell was invisible; fixed |
| 0x31 | Lightning | the zap sets the shrunk size (0.5) and destroys an active mushroom effect; the shrink timer resets the size |
| 0x32 / 0x34 | Deku Nut, Pitfall | held, thrown, damage |
| 0x33 | Franklin Badge | consumed; reflect is in `ftremixreflect.c` |
| 0x35 | Golden Gun | the golden bullet fires: `projectile_info` and its display list, image and vertices are copied from the RAM image into the scene arena as a small reloc file (`remix_ram_image_make_file`); bullet damage 99 |
| 0x36 / 0x37 | Dango, P-Wing | consumed (heals; wings on the fighter) |
| 0x39 | Stopwatch | consumed |
| 0x40 | Basketball | the asm `item_info_array` continues into state 0 at 0x14, so the `ITDesc` procs are the MAIN procs (they were NULL and the ball did not move); the per-ball state is a pool slot per ball instead of one global |
| 0x41 | Psyduck | disabled in Remix 2.0.1 itself (`Toggles.entry_pokemon_psyduck` is commented out of `pokemon_table`, `NEW_POKE = 0`); the model is Hitmonlee's placeholder |

Transform words of every item `ITDesc` were compared with the asm word 0x0C (0x1B = `TraRotRpyR`, 0x1C = `TraRotRpyRSca`,
0x12 = `Tra`): Blue Shell, P-Wing, Stopwatch and KlapTrap were corrected. `Interpreter::SegAddr` (libultraship) resolves raw
addresses owned by the RAM-image fallback (`portRelocResolveFallbackAddress`).

## Generator bug: `tools/gen_remix_actions.py` wrote garbage into `ftremixvanillaprocs.c`

`vanilla_return_types` read each routine's return type from the line number in `vanilla_funcs.txt`. Those numbers go stale when
a decomp file is edited, so the "type" became half of a statement and the generated `extern` lines did not compile (about 20
errors). It now checks the hinted line against a definition pattern, falls back to searching the file for the definition, and
stops with an error if none exists. The script also has `EXTRA_SYMBOLS` (`Stages.custom_item_spawn_rate_table`,
`Stages.series_logo_table`).

Open gaps: `docs/remix/patch_audit.md`, group g4.
