# Remix stages: loader, ground makers, stage select, music and hazards

How the port loads and runs the 175 Remix stage ids (0x29 to 0xD7). Code: `decomp/src/gr/grremix/` (stage loader, ground
dispatch, hazards), `decomp/src/it/itremix/` (hazard items), `decomp/src/mn/mnmaps/` (stage select),
`tools/gen_remix_stage_ids.py` and `tools/gen_remix_actions.py` (generated ids and symbols). Test: `stage_sweep.sh [first]
[last]` (every id, 480 frames, screenshot at 450), `hazard_sweep.sh <stage>...` (4000 frames, a shot every 150, sheet per stage),
`stage_select_sweep.sh`, with `SSB64_VS_STAGE=<decimal>` (`.claude/skills/remix-smoke-tests/SKILL.md`). `vs.sh` with a single
fkind ignores `SSB64_VS_STAGE` (it boots Dream Land): pass at least two fkinds.

## Loader and dispatch

- **Loader.** `Stages.stage_file_table` is the vanilla `dMPCollisionGroundFileInfos` grown to the Remix ids: {map file id,
  header offset}. `grRemixGetGroundFileInfo` (`grremixstage.c`) reads it from the Remix RAM image and
  `mpCollisionInitGroundData` uses it for gkind > 0x28. The port's gkind is the Remix stage id (`grremixids.h`, generated by
  `tools/gen_remix_stage_ids.py`). `tools/gen_remix_actions.py` exports the stage tables (`EXTRA_SYMBOLS`) and every
  `Hazards.*` symbol (`EXTRA_SYMBOL_PREFIXES`).
- **Ground maker.** `grMainSetupMakeGround` -> `grRemixMakeGround` dispatches on `Stages.function_table`: a vanilla maker
  address, `GRREMIX_FUNC_CLONE` (no hazards, 75 stages) or a Remix hazard routine, handed to `grRemixHazardsMakeGround`
  (`grremixhazards.c`, one `grremixhazards_<stage>.c` per stage).
- **Gating of the vanilla makers.** Remix keeps the vanilla maker for clones and patches the hazards inside it (`Hazards.asm`
  toggles, `mk_clone_hazard_removal_`, `congo_jungle_barrel_`). The port gates them under `REGION_REMIX` (`grremixgating.c`,
  `grcommon/grjungle.c`, `grinishie.c`, `grzebes.c`, `grcastle.c`, ...). This fixed the crashes of the Mushroom Kingdom clones
  (65, 66, 155) and the Saffron clones (114, 118).
- **Wallpaper.** `Stages.bg_type`: every Remix stage uses the common wallpaper, Remix RTTF (0xBD) none
  (`grWallpaperMakeDecideKind`).
- **Music.** `grRemixGetStageBGM` (`grremixstage.c`): the `default_music_track_table` override, then the Occasional, Rare and
  Rare2 alternates by chance (65/16/10/9), applied in `mpCollisionInitGroundData` for VS.
- **Stage select.** `mnMapsBuildRemixPages` (`mnmaps.c`, `mnremixstagepages.c`) builds the pages at open from
  `Stages.stage_table_normal` (or the tournament table). Icons come from the Remix icon file (0xA04, `icon_offset_table`),
  names are typeset with the CSS font, and the preview zoom and translation come from `zoom_table` / `position_table`.

## Findings and deviations

1. **KlapTrap** did not show: `itremixklaptrap.c` hides the item at spawn (GObj camera tag 0), starts the joint track (file +
   0x0908) and the material track (file + 0x0E20) at each respawn and shows it when the hitbox arms.
2. **Hazard intro check** `grRemixHazardsMatchHasStarted()`: Great Bay, Twilight City, Pirate Land water and Japes skip
   fighters before the match clock starts, as the asm does.
3. **Hazard item animations.** The base of the track offsets for the KlapTrap, Robot Bee and Cacodemon is not the stage header
   but the item pointer at header + 0xE0 minus 0x07E8 (the asm saves it at 0x801313F0): `grRemixHazardsItemFileTop`.
4. **Pirate Land cannonball** explodes when its model animation ends (GObj `anim_frame <= 0`), not after 999 frames.
5. **Bowser's Stadium bombs** need `BOWSER_BOMB_HEADER` (file 0x9B2), loaded in `grRemixBowserBombsStart` as the RTTF bomb item
   file.
6. **Scuttle Town minions are off in Remix 2.0.1 itself** (`b _end` in `scuttle_town_setup_`); the port mirrors that
   (`GRREMIX_SCUTTLE_MINIONS_ENABLED`) after the minion item crashed in `gcSetupCustomDObjsWithMObj` (its file offset 0x40 does
   not match the standard footer layout).
7. **Peach's Castle II Banzai Bill is a placeholder in Remix 2.0.1 itself.** `banzai_bill_factory_` ends the match path with
   `b _end` ("prevent spawn crash until the item object works"), so in a real match nothing spawns; only Training reaches the
   spawn, and there the asm creates `Item.RobotBee.id`, not Bullet Bill. The port keeps the same gate (Training only) and spawns
   the Bullet Bill item (0x3D) the author intended, since the Robot Bee needs the Metallic Madness file. This is the only
   deliberate difference from the asm in the hazards; the Scuttle Town minions are off for the same reason.
8. **Stage 59 (Mementos) and Dream Greens (149) crashes**: Mementos failed on an unresolved map pointer token, fixed in the
   reloc loader (`reloc_chain_fixup_overwrites_pending_slot_2026-10-14.md`); Dream Greens needed the
   `dream_greens_hardcoding_*` and `_animation_*` routines (`grcommon/grpupupu.c`, table read from the RAM image).
